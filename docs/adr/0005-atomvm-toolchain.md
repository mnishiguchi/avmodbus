# 0005: AtomVM と開発用ツールのバージョンを分けて管理する

## 背景

AtomVM の対象ブランチ、実機のファームウェア、ホスト側の API 定義、Erlang / Elixir の開発ツールでは、用途と更新時期が異なる。

## 決定

- 対応対象は AtomVM `release-0.7` とする
- 通常の実機検証には公式の ESP32-C5 向け `v0.7.0-beta.0` イメージを使う
- ソースからのビルドは、対応する ELF / map が必要な AtomVM 本体のクラッシュ調査に限定する
- `:atomvm` は対応 API の情報を参照するためのビルド時依存とし、実行時には含めない
- ホスト側のツールは `.tool-versions`、依存パッケージのバージョンは `mix.exs` / `mix.lock` に合わせる

## 再評価

AtomVM の新しい公式イメージや API 定義パッケージが公開されたら、実機での動作とホスト側の検証を
別々に確認してから更新する。
