# 0003: シリアル通信の管理方針を Client / Server で共有する

## 背景

1 本のシリアル通信路では、要求と応答、フレームの間隔、タイムアウト、一斉送信、切断後の復旧を一貫して扱う必要がある。

## 決定

- 管理用プロセスが UART を所有し、要求を順番に処理する
- キューでの待ち時間も処理期限に含める
- RTU のフレーム間隔、一斉送信後の待機、必要に応じたエコー除去をトランスポート層で扱う
- UART に障害が起きたら、待ち時間に上限を設けた指数バックオフで再接続する
- Server が Unit ID による振り分け、一斉送信、診断機能、受信専用状態を管理する
- RTU / ASCII で要求の振り分け、ハンドラー、再接続の方針を共有する

## 影響

UART の所有者と復旧する責任が明確になり、RTU と ASCII の動作の違いを減らせる。
